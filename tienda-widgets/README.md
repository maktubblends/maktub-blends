# Widgets de la tienda

Widgets propios para maktubblends.com.ar (Tiendanube): pasos de preparación, lista de beneficios e información de despacho y tira de fotos del producto con desplazamiento continuo, precio por taza, cinta de ingredientes, medidor de intensidad y cinta de reconocimientos, carrusel de accesorios y orden de secciones en el inicio.
Se cargan desde el código personalizado del theme vía jsDelivr.
